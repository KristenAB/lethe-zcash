Three quotes. Three refund addresses. No shared refundTo.

A swap out of Zcash through NEAR Intents 1Click names a refund address, and 1Click marks that request public. A wallet that reuses its address there links every swap it makes. zswap gives each swap a one-time refund key instead.

Refunds stay recoverable

1Click has no testnet, so a demo wallet paid each one-time testnet address as a stand-in refund. A compact-block scan with every reserved key found each payment with its own key only; the account's ordinary key saw none of them.

refund 0e08cfef2…found by key 030,000 zat

Limits

  • No real swap yet: a live quote creates a mainnet deposit address and needs mainnet ZEC.
  • The key derivation (zakura-one-time-ivk 0.0.1-rc1) is a draft and says it is not for live addresses before review.
  • Amounts, timing and the destination-chain recipient can still link swaps. This removes the refund-address link only.
  • Not audited.
