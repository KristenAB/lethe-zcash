1: //! One-time refund addresses for swaps out of a Zcash wallet.
2: //!
3: //! A swap provider (NEAR Intents 1Click) is told a `refundTo` address. If every swap names the same
4: //! wallet address, anyone reading those public `refundTo` fields can link all of a user's swaps (and
5: //! a future quantum adversary gains more from each link). Here swap `i` gets a **one-time key**
6: //! derived with `zakura-one-time-ivk`: it keeps the account's spending authority (`ak`, `nk`) and
7: //! gets its own `rivk`, so it has its own incoming viewing key and address. Two refund addresses
8: //! cannot be linked to each other or to the account address from the addresses alone.
9: //!
10: //! `zakura-one-time-ivk` is a draft convention ("must not be used to issue live addresses before
11: //! review"). This crate uses it on Zcash testnet only, and for mainnet `refundTo` in *dry* quotes,
12: //! which create no deposit address and move no funds.
13:
